## About

This repository contains the source code for a paper describing the concept of the "Version Control Course" at University of Hamburg, prepared for the teaching award at the Institute of Psychology.
Built with [Quarto](https://quarto.org/).

This concept paper summarizes content, structure, and didactic methods of the full-semester course "Track, organize and share your work: An introduction to Git for research" by [Dr. Lennart Wittkuhn](https://lennartwittkuhn.com/).
An online version is available at [https://lennartwittkuhn.com/version-control-course-concept](https://lennartwittkuhn.com/version-control-course-concept).
A PDF version is archived at [doi: 10.25592/uhhfdm.16245](https://doi.org/10.25592/uhhfdm.16245).
It was prepared for the Teaching Award 2024 at the Institute of Psychology, University of Hamburg.
More details about the course can also be found in this [project description](https://www.isa.uni-hamburg.de/en/ddlitlab/data-literacy-lehrlabor/zweite-foerderrunde/06-git.html), this [project report](https://lennartwittkuhn.com/ddlitlab-report/), and a [20-minute video interview](https://lecture2go.uni-hamburg.de/l2go/-/get/v/70364) (in German).
